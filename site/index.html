How it works

  1. Pick a base agent. Eighteen ship with the app, each with intake questions, playbooks, benchmarks, a quality checklist and guardrails.
  2. Cross it with an area and your needs. Choose from 28 niches and channels, describe your situation, pick English or Portuguese. Claude Code rewrites the whole agent for that context.
  3. Review, save, install. The file lands in your library folder as plain Markdown. One click copies it into Claude Code.
