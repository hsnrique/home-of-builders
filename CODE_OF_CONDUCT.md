# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give feedback on the work and not the person, and keep discussions about the project.

## Reporting

Report unacceptable behavior to the maintainer, Henrique Braga, through the contact details on [hsnrique.com](https://hsnrique.com), or use GitHub's **Report content** option on the comment or issue. Reports are handled privately.
